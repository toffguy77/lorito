## Why

Before submitting 2.0 the owner asked to refresh the App Store page and fill the
marketing surfaces: the 2.0 screenshots still showed the six-scene stage-1 story with a
stale count («892 упражнения»; the bundle has 937), the 2.0 promotional text was empty in
App Store Connect, the description listed 13 word decks (58 ship), and there were no app
previews, creative assets (product page header, search results), custom product pages,
in-app event or featuring nomination.

Owner decisions (2026-10-30): a new screenshot story; app previews, custom product
pages, an in-app event and featuring art all prepared; uploads to App Store Connect
only after the owner approves the copy and media.

## What Changes

- Screenshots: eight scenes per device class from the demo store — Today, common
  mistakes, DELE A2 track, conjugation trainer, exercise, Spanish variant (setup re-run),
  recall front, progress — with new Russian headlines. The demo store gains a DELE A2
  date and the conjugation and words trainers.
- Metadata: promotional text, description and «Что нового» updated to the 2.0 feature
  set and the bundle's counts (ru, es-ES, es-MX).
- App previews: a recorded walkthrough per device class (iPhone 886×1920, iPad 1600×1200)
  with Russian scene captions, generated by `tools/record_app_preview.sh`.
- Creative assets: product page header (3840×1646) and search results (3840×2560),
  rendered from `design/marketing/` by `tools/render_marketing.sh`.
- Custom product pages (DELE/CCSE exams, Spanish citizenship, verbs and subjunctive),
  an in-app event for the 2.0 release and a featuring nomination: copy in
  `fastlane/marketing/copy.json`, media in `fastlane/marketing/media/`.
