## MODIFIED Requirements

### Requirement: Benefit-led screenshot set
Each device class (iPhone and iPad) SHALL have eight screenshots generated by UI tests from a seeded demo store — Today plan, revealed card with common mistakes, DELE A2 exam track, conjugation trainer, exercise, Spanish variant choice, recall-first card front, progress — each with a one-line Russian benefit headline. Counts in headlines SHALL match the content bundle.

#### Scenario: Screenshots regenerated
- **WHEN** the screenshot UI tests run with the demo store for iPhone and iPad
- **THEN** eight framed screenshots with headlines and non-empty data are produced per device class

## ADDED Requirements

### Requirement: App previews
Each device class SHALL have an app preview recorded from the app running on the demo store — 15 to 30 seconds, H.264 at 30 fps, with a silent stereo AAC track — at 886×1920 for iPhone and 1600×1200 for iPad, showing only app screens with short Russian captions, generated by a repository script.

#### Scenario: Preview within Apple's limits
- **WHEN** the preview script finishes for iPhone
- **THEN** the file is 886×1920, 30 fps, H.264 with a stereo AAC track, and between 15 and 30 seconds long

### Requirement: Marketing surfaces prepared in the repository
The repository SHALL hold the copy and media for the product page header, the search results asset, custom product pages, an in-app event and a featuring nomination, within Apple's size and length limits, without prices, URLs, awards or other platforms in the media, and SHALL be uploaded to App Store Connect only after the owner approves them.

#### Scenario: Creative asset sizes
- **WHEN** the media are rendered
- **THEN** the header is 3840×1646, the search results asset 3840×2560, the event card 3840×2160 and the event details 2160×3840, all without an alpha channel

#### Scenario: Event copy limits
- **WHEN** the in-app event copy is checked
- **THEN** its name has at most 30 characters, the short description at most 50 and the long description at most 120
