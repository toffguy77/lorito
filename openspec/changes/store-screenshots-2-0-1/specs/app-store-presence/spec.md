## MODIFIED Requirements

### Requirement: Benefit-led screenshot set
Each device class (iPhone and iPad) SHALL have eight screenshots generated by UI tests from a seeded demo store — Today plan, revealed card with common mistakes, DELE A2 exam track, conjugation trainer, exercise, Spanish variant choice, recall-first card front, progress — each with a one-line Russian benefit headline. Counts in headlines SHALL match the content bundle. Each headline SHALL be true of the screen it frames: a headline naming a feature or exercise type SHALL appear over a screen that shows it. The common-mistakes and recall scenes SHALL show a card about a mistake specific to Russian speakers (such as noun gender or ser/estar), with the «Частые ошибки» block fully inside the frame.

#### Scenario: Screenshots regenerated
- **WHEN** the screenshot UI tests run with the demo store for iPhone and iPad
- **THEN** eight framed screenshots with headlines and non-empty data are produced per device class

#### Scenario: Exercise headline matches the exercise
- **WHEN** the exercise scene's headline names listening, writing and speech
- **THEN** the captured exercise is a listening or dictation exercise, not a plain multiple choice

#### Scenario: Mistakes block framed
- **WHEN** the common-mistakes scene is captured
- **THEN** the «Частые ошибки» heading and all its items are visible and no line is cut at the top of the card

## ADDED Requirements

### Requirement: No error states in store media
Screenshots, app previews and marketing art SHALL NOT show error, unavailable or setup-required states (for example the iCloud-required note of «Учиться вместе»), and every figure visible in one capture SHALL be consistent with the others in that capture. The demo store SHALL show activity in the current week: new rules introduced this week and reviews done today.

#### Scenario: Progress without iCloud
- **WHEN** the progress scene is captured on a simulator without an iCloud account
- **THEN** no «Учиться вместе» card or iCloud note is visible

#### Scenario: Weekly recap not zero
- **WHEN** the Today scene is captured
- **THEN** the weekly recap shows at least one new rule and the progress screen shows a non-zero count for today

### Requirement: Exam body disclaimer in the description
Every localization whose description names Instituto Cervantes, DELE or CCSE SHALL state that Lorito is not affiliated with Instituto Cervantes.

#### Scenario: Disclaimer present
- **WHEN** the metadata lint runs on a description that contains «Instituto Cervantes»
- **THEN** it fails unless the description also contains «не связан с Instituto Cervantes»

### Requirement: Custom product pages refreshed without an app release
When store screenshots change, the custom product pages SHALL get a new page version with the new screenshots through the App Store Connect API, without waiting for an app version, and only after the owner approves the media.

#### Scenario: Refresh before the next app version
- **WHEN** the screenshots are re-captured while the app version is locked for release
- **THEN** each custom product page gets a new version with the new screenshots, submitted for review, and its keywords and promotional text are kept
