# Proposal

## Why

Все 937 упражнений сейчас открываются только из ридера отдельной карточки
(«Практика · N» под текстом правила). Когда теория уже понятна, удобно
тренироваться без карточек: в смешанном наборе, по своим ошибкам, по теме
или уровню. Сейчас для этого приходится открывать карточки по одной.

## What Changes

- Новая **свободная практика** упражнений вне ридера карточки с четырьмя
  режимами:
  - «Смешанная»: выборка из упражнений всех изученных карточек;
  - «Слабые места»: упражнения, последний ответ на которые был неверным;
  - «Практика по теме» и «Практика по уровню».
- В подбор попадают **только упражнения изученных карточек** (статус не «новая»).
  Пользователю прямо говорят, что упражнения открываются по мере изучения
  карточек: подпись к входу, счётчик «доступно X из Y» и пустое состояние
  с объяснением.
- Точки входа: строка **«Практика»** на экране «Сегодня» рядом со
  «Спряжениями» и «Словами» (открывает «Смешанная» и «Слабые места»), а также
  кнопки **«Практика по теме»** (список карточек темы) и **«Практика по уровню»**
  (Каталог). Новой вкладки нет.
- **Компромисс по SRS для свободной практики.** Неверный ответ (и самооценка
  «Опять») влияет на расписание карточки так же, как сейчас. Верный ответ
  записывается только как попытка и расписание не сдвигает. Практика из
  ридера карточки работает как раньше. Правило «только первая оценка
  элемента за учебный день» сохраняется.
- Свободная практика становится функцией **Lorito Pro**. Пока продажи
  выключены, она доступна всем. Практика из ридера карточки остаётся
  бесплатной.
- Новое событие аналитики: старт свободной практики (режим и число упражнений).

Вне скоупа: показ упражнения вместо карточки в учебной сессии при
повторении (отдельное изменение).

## Capabilities

### New Capabilities
- `practice-hub`: свободная практика упражнений вне ридера карточки. Режимы,
  правило подбора (только изученные карточки), выстраивание ожиданий
  (подписи, счётчики, пустые состояния), точки входа на «Сегодня» и в
  Каталоге, сессия и её завершение.

### Modified Capabilities
- `practice-exercises`: «Practice result feeds the existing SRS» теперь
  различает практику из ридера (как раньше) и свободную практику (только
  неверный ответ влияет на расписание, верный записывается как попытка).
- `monetization`: «Pro scope is the exam path only» расширяется до exam path
  и свободной практики. «Sales switch» при выключенных продажах даёт право и
  на свободную практику.
- `product-analytics`: добавлено событие старта свободной практики.

## Impact

- **Domain**: подбор упражнений для режимов (чистая функция поверх каталога,
  статусов карточек и `ExerciseAttempt`); путь оценки свободной практики в
  `ExercisePracticeService`; `ProFeature` получает случай практики;
  `PaywallEntry` и `AnalyticsEvent` получают новые случаи.
- **Features**: строка «Практика» и лист режимов на «Сегодня»; кнопки
  практики по теме и уровню в `CatalogView`; `ExerciseSessionModel` получает
  режим оценки (ридер или свободная практика); пейвол для новой точки входа.
- **Persistence / CloudKit**: без изменений схемы. Попытки уже
  синхронизируются; новых полей и записей нет.
- **UI-тесты**: новые идентификаторы доступности; iPhone и iPad.
- Скриншоты App Store не затрагиваются.
