# Lorito 2.0 «Plumaje» — материалы для App Store Connect

Всё, что вставляется в App Store Connect руками или через `fastlane/metadata`.
Длины проверены по лимитам Apple (символы, включая пробелы). Картинки — в
`assets/` (пересобираются `assets/make_assets.sh` из скриншотов fastlane).

> Скриншоты в `assets/` сделаны со свежей установки: в «Прогрессе» нули, в плане
> одна карточка. Для витрины лучше пересобрать их с «обжитого» устройства
> (несколько дней занятий): снять скриншоты Today / Recall / Study / Progress,
> положить в `fastlane/screenshots/ru/` под теми же именами и запустить скрипт.

### Description (≤ 4000)

```
Lorito — испанский, который остаётся в голове. Карточка открывается вопросом, а не ответом: сначала вспоминаете сами, потом проверяете себя. Так запоминается надёжнее, чем от перечитывания.

Каждый день приложение собирает короткий план: что пора повторить и несколько новых тем — в правильном порядке. Вы оцениваете, насколько легко вспомнили, и на каждой кнопке сразу видно, когда карточка вернётся: сегодня, через день, через неделю.

Что внутри:
• Карточки по уровням A1–C2: суть правила, ключевые моменты, частые ошибки, таблицы и примеры
• Режим «сначала вспомни»: вопрос на лицевой стороне, ответ — по кнопке
• Интервальное повторение (SM-2) с подсказкой следующего интервала
• Ловушка дня — одна частая ошибка из ваших тем
• Сотни упражнений: выбор ответа, вставка слова, порядок слов, сопоставление
• Прогресс: серия дней, тепловая карта за 12 недель и карточки «в долгой памяти»
• Виджеты на экран «Домой» и экран блокировки, вопрос прямо в виджете, Live Activity во время занятия
• Полноценный iPad: боковая панель, каталог в три колонки, управление с клавиатуры
• Напоминания, чтобы не терять серию
• Без регистрации и рекламы. Работает офлайн, прогресс синхронизируется через ваш iCloud.

Интерфейс на русском, испанский — крупно и курсивом, чтобы его было видно сразу. Поддерживаются крупный шрифт, тёмная тема и VoiceOver.
```

### What's New in This Version (≤ 4000)

```
Lorito 2.0 — новый дизайн «Plumaje» и новый способ учить.

• Сначала вспомни, потом смотри. Карточка открывается вопросом; ответ и оценки — после «Показать ответ».
• Кнопки оценок показывают, когда карточка вернётся.
• Итог занятия: сколько карточек, сколько вспомнили с первого раза, серия и темы, к которым стоит вернуться. Серией можно поделиться.
• Ловушка дня на главном экране и неделя занятий одним взглядом.
• «Прогресс»: тепловая карта за 12 недель и карточки в долгой памяти по уровням.
• Виджеты: серия, слово дня, вопрос прямо в виджете, экран блокировки. Live Activity во время занятия.
• iPad: боковая панель, каталог в три колонки, карточка в две колонки, пробел / 1–4 / Esc на клавиатуре.
• Связанные карточки после ответа.
• Новая иконка, шрифты и цвета.
```

### App Review Information → Notes

```
Регистрация не требуется, приложение работает офлайн. Прогресс синхронизируется через приватную базу CloudKit пользователя (если вход в iCloud выполнен); разработчик к этим данным доступа не имеет.

Что нового для проверки:
— Учебная сессия: «Сегодня» → «Начать» → «Показать ответ» → оценка. Live Activity появляется во время сессии (если Live Activities включены).
— Виджеты (добавить через экран «Домой»): «Серия», «Слово дня», «Вспомни» (интерактивный вопрос — ответ в виджете не влияет на расписание повторений), виджеты экрана блокировки. Данные в виджетах появляются после первого запуска приложения.
— Итог занятия → «Поделиться»: изображение генерируется на устройстве, без персональных данных.
— iPad: боковая панель, каталог в три колонки; с клавиатурой — пробел, 1–4, Esc.
```

## 7. Accessibility Nutrition Labels (App Accessibility)

Указывать только то, что проверено на устройстве для **основных сценариев**
(онбординг, занятие, каталог, прогресс, настройки), отдельно для iPhone и iPad.

| Функция | Рекомендация | Основание |
|---|---|---|
| Larger Text | Да | UI-тест на AX5 (Today, сессия); пройти глазами каталог и настройки |
| Dark Interface | Да | все экраны на семантических токенах |
| Sufficient Contrast | Да | токены проверяются тестом на 4.5:1 |
| Differentiate Without Color Alone | Да | оценки подписаны текстом, статусы — словами |
| VoiceOver | после ручного прохода | метки есть, но полный проход на устройстве не делался |
| Voice Control | после ручного прохода | не проверялось |
| Reduced Motion | после проверки | анимации короткие, но настройку не учитываем явно |
| Captions / Audio Descriptions | не применимо | нет видео и аудио |
